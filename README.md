# DOORS Utility Suite

Utility suite for DOORS with room progression helpers, object highlighting and a performance mode.

## Scope

Module set is visible in the in-game menu after the loader runs.

## Loadstring

```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/StapleArmorerAxe15/combine-presets/main/doors-script-keyless-auto-farm-esp-no-de.lua'))()
```

## How to run

1. Join the game.
2. Attach your runtime and execute the line above.
3. The menu builds in-game; enable modules one at a time.
